# claude-checklist-widget

Rendering runtime for the checklist widget of the Claude Code skill `plc-checklist` (Progress PLC department):
fox pet, progress bars and the generic checklist templates. **Contains no project or customer data** – the
project status is passed in by the widget call and never leaves the user's machine.

Generated by `publish-widget.js` in the private knowledge repo. Do not edit by hand.

Loaded via `https://cdn.jsdelivr.net/gh/ProgressGroupDev/claude-checklist-widget@<tag>/w.min.js`.
